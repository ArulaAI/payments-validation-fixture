RECOVER / 15 MINUTES

Change one supported cause.

Keep the raw response, useful commits, patches and task state. Choose a permitted correction or return an owner decision.

01

Follow the dependency

Locate the producer’s completion, its merge into the target and the consumer’s new context. Concurrency cannot remove a real dependency.

02

Read the actual result

Agent completion, task done, process exit and feature completed are separate records. Inspect pending and blocked work alongside failed counts.

03

Preserve useful prior work

Retry appends guidance and normally returns eligible work to pending. Inspect branch audit before the next Run; avoid blanket branch recreation.

04

Keep the accepted source and original failure. Compare the next candidate against both; do not weaken tests to fit generated code.

Retain a bounded observation

“Task 1 can crash on a rejected model call.”

Cite the review finding at src/risk/scoring.ts:52 and its commit. It describes that code, not every model call.

Reject an unsupported rule

“All unavailable paths hold.”

Consult both F2 RFCs. One path’s fallback cannot silently change the other’s accepted contract.

Memory can become active automatically. Single-player synthesis has no mandatory human approval screen. A review note does not gate injection. Inspect the actual files and stop future use of unsafe advice.

07 / The handoff

Same fixture. Clear responsibility.

Give 301.3E a candidate
it can independently validate.

The receiving engineer should locate the original intent, candidate, evidence and unanswered questions without relying on the presenter’s explanation.

01 / SOURCE AND CANDIDATE

Make it reproducible.

Original 301.1E baseline, reviewed specifications, task scope, accepted decisions, target and candidate SHA.

02 / EVIDENCE AND LEARNING

Keep the limits visible.

Command results, unavailable checks, recovery history, observation IDs, active memory and actual context.

01

Name the next accountable decision

Choose candidate, bounded partial scope or blocked handoff. Keep Product, Risk, Legal and release decisions with their owners.

02

Keep independent validation independent

301.3E chooses methods for the candidate’s risks. Integration checks and learned advice do not substitute for that judgment.

INDIVIDUAL TRANSFER / 20 MINUTES

Defend an unfamiliar decision.

One packet, source-linked diagnosis, recovery/learning judgment and a written counterfactual. Label live and recorded participation.

HANDOFF AND CLOSE / 10 MINUTES

Let another engineer start.

Swap packets. Locate the candidate, original requirement, active learning and one unresolved owner without oral explanation.

Before live delivery. The snapshot, handoff and recorded checkpoint come from one run at a8bde62. Still to do: one rehearsal with Claude as provider and a cohort to calibrate timing and scoring.
