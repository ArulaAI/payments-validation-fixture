# 301.2E course assets

Continue the original payments fixture and actual reviewed 301.1E adaptive-auth handoff.
These assets inspect and record that work. They contain no replacement application,
prepared execution plan or implied owner approval.

| Asset | Purpose |
| --- | --- |
| `handoff-301-1e.example.json` | Explicitly blocked schema example; fill from actual reviewed source, scope and reports |
| `inspect-handoff.py` | Read-only structural consistency check; does not grant semantic acceptance |
| `run-and-record.py` | Retains actual command, console, exit and command-startup failures in a new directory |
| `capture-evidence.py` | Snapshots task/context/code/spec and learning-memory evidence without overwrite |
| `preview-learning-context.sh` | Calls the installed single-player developer context bridge without starting agents |
| `verify-assets.py` | Synthetic utility safeguard checks; no provider calls or F2 validation claim |
| `templates/` | Execution, integration, learning review, individual scoring and 301.3E handoff |

The inspected SPEED source manifest and the rehearsal summary are trainer material and
live in [`../../instructor/`](../../instructor/).

Start with the [workbook](../learner-workbook.md). The trainer prepares
independent, source-matched live and recorded checkpoints from the same 301.1E packet.
Keep raw logs private until reviewed. Instruction time, waits and assessment total
120 minutes; provisioning happens before the session and learners need no extra homework.
