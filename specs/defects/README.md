# Defects

Defect reports for the payments service. One file per defect, named for the behaviour
rather than the symptom.

Use [`TEMPLATE.md`](TEMPLATE.md). Severity, reproduction and observed behaviour are
required. Verbatim error text, not a paraphrase.

A defect report is a claim, and the evidence that supports it belongs in the report. State
which check surfaced it and what that check's result actually proves. A finding from a
scanner and an opinion from a reviewer are not the same claim, and a report that does not
say which it holds cannot be acted on.
